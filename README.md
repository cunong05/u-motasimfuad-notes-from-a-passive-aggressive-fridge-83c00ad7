# Notes From a Passive-Aggressive Fridge

A make.fun bounty entry. The program writes one funny passive-aggressive note — a single line, 1–200 characters — that a smart fridge leaves for its owner, to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.

## The note

> You opened me 14 times today, ate nothing, then told your friends I'm always empty. The yogurt heard you. So did I.
